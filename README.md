## 🌟 Overview

Welcome to **AI-BOT**, a state-of-the-art conversational web application designed with modern aesthetics and powerful backend integrations. Moving beyond standard chat interfaces, AI-BOT implements a stunning **glassmorphism UI** that is fully responsive and supports multiple customizable themes (including a sleek Dark Mode). 

Under the hood, it leverages a robust **Flask** backend combined with high-speed AI inference architectures, supporting seamless integration with **OpenAI**, **Llama-3**, and **Multilingual OpenRouter** networks.
